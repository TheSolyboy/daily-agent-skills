# daily-agent-skills

One useful agent skill every day. Not my own skills, just good ones I use and think more people should know about.

Each folder has a `SKILL.md` you can drop into your agent's skills folder, plus a short readme on how to use it.

| Day | Skill | What it does |
|-----|-------|--------------|
| 1 | [Context Transfer](day-01-context-transfer) | Moves a full chat into a new one without losing anything |
| 2 | [HyperFrames](day-02-hyperframes) | Write one prompt, get a real MP4 video |
| 3 | [Security Audit](day-03-security-audit) | Turns your agent into a security auditor that double checks its own findings |
| 4 | [Graphify](day-04-graphify) | Turns your whole project into a graph your agent can query |

New one every day. Posted on X: [@soly_nex](https://x.com/soly_nex)

Credit goes to the original authors, linked in each skill's readme.
